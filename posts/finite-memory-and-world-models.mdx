Nick Bostrom’s 2003 paper on the simulation argument made me think about what an observer can infer about the system that generates its experience. An observer has access to what happens inside that system and has to reason about what produced those observations. I wanted to connect that question to world models, where an agent learns about its environment from experience and then uses what it learned to decide what to do. [Bostrom’s paper](https://doi.org/10.1111/1467-9213.00309)

I split the work into two parts. The first asks what can be inferred with a strict limit on memory. The second asks when a learned model is reliable enough to use for planning. They share a question about what an observer can infer from the information available to it, but the mathematical setup and the experimental setup answer different questions.

## Finite-memory hypothesis testing

Imagine watching a stream of zeros and ones. The chance of seeing a one alternates between a higher and a lower value, but you cannot see which phase the source started in. The test has to decide which of two possible sources generated the stream. In this setting the hidden phase is sampled once, at the start. The observations provide indirect evidence about it.

Now give the observer just three internal states. After each observation it can move to another state, but it cannot keep the full history. At the end, the state it occupies is all it has available for the decision. A deterministic observer always makes the same transition for a given state and observation. A randomized observer can choose between transitions with fixed probabilities. Both have the same number of states. The question is whether changing the transitions alone can improve the final decision.

**Manuscript 1 — Four observations.** The first manuscript gives an exact example in which a randomized three-state observer does better than the best deterministic observer in the comparison. The four-observation horizon is short enough to compare the constructions exactly. The result matters because the improvement comes with the same memory budget. Randomization changes how evidence is carried forward through those three states.

**Manuscript 2 — Three and five observations.** The second manuscript asks how the comparison changes when the observer has to decide earlier or later. It works out the deterministic optima and gives explicit randomized constructions at three and five observations. It also examines the source bias, which controls how strongly the high- and low-probability phases differ. This lets me ask how the gap changes as the underlying signal gets weaker, rather than relying on one numerical instance.

**Manuscript 3 — Exact and approximate testing.** The third manuscript changes what is held fixed. Instead of giving the observer three states, it asks how many states are needed to match the optimal decision rule exactly as the number of observations grows. It then studies what happens when we allow a small increase in the probability of error. In the model studied, exact testing requires a state budget that grows with the horizon. For a fixed positive tolerance, a bounded counter can suffice once the horizon is long enough. The counter preserves an accumulated signal up to a limit, giving a concrete way to trade a small amount of accuracy for a smaller memory budget.

I will add publication details and links for the three manuscripts as they become available.

## World models

A world model learns how a state changes after an action. A planner can use the model to simulate several candidate action sequences, estimate the outcome of each, and choose what to do. The model’s predictions are then used as inputs to later predictions. A small error on one step can propagate through the rest of the simulated trajectory, especially if the planner considers actions that take the model into states it has rarely seen.

For a concrete example, imagine a planner deciding whether to brake now or in two steps. The learned model slightly underestimates how far the system will travel at each step. That difference may be small in a prediction report, yet after several steps it may make the late-braking option look safer than it is. A larger error elsewhere may leave the preferred action unchanged. I want to measure both effects by comparing the model’s forecasts with the reference environment and checking whether the model changes which action the planner prefers.

The first practical step is to measure how errors accumulate. In my Latent Dynamics Benchmark, a linear transition model is fitted on seeded synthetic trajectories. The benchmark evaluates free-running predictions on held-out trajectories, reports error over a specified rollout horizon, and compares it with a persistence baseline that predicts the state will stay where it is. The reference dynamics are known, so the error is directly measurable. This experiment measures state prediction in a one-dimensional system. The next experiment adds planning and evaluates the selected action sequence in the reference environment. [Latent Dynamics Benchmark](https://github.com/MonikaDvorackova/latent-dynamics-bench)

The connection to Bostrom is the question about what an observer can infer about a system it experiences from within. For world models, I can make part of that question testable by fixing a reference environment, controlling what the agent sees, and measuring the consequences of planning with a learned model.
