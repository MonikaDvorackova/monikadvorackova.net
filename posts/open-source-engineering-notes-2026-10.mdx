*Updated November 11, 2026.*

These notes started with a one-line Python packaging fix. The work since then has ranged from a null symbol in LLVM to duplicate computation in a local cache. Here I record what each change addresses, how it was checked, and where it stands upstream. The index below also includes earlier public pull requests and links to my own public projects.

## Python and data infrastructure

**CPython.** On POSIX, the optimized paths in `fnmatch.filter()` and `fnmatch.filterfalse()` could bypass normalization of individual names. A `pathlib.Path` then reached the pattern matcher in a form it could not handle. The patch normalizes each name and adds regression coverage for both filters. The targeted `test_fnmatch` suite passed locally. The PR remains open. [CPython #160980](https://github.com/python/cpython/pull/160980)

**fsspec.** A recursive copy can enumerate both files and directories. On S3, a virtual directory can appear in that listing without an object at the directory path for `cp_file` to copy. The proposed fix handles directories with `makedirs(exist_ok=True)` in the synchronous and asynchronous paths. Errors copying real files still propagate and stop a move before it deletes the source. Eight regressions failed on the original code and passed after the change. The relevant suites reported 891 passes, 36 skips and one expected failure. A local Moto S3 test verified destination bytes and removal of the source objects after a successful move. The PR remains open. [fsspec #2448](https://github.com/fsspec/filesystem_spec/pull/2448)

**joblib.** Concurrent `Memory` calls can each compute the same missing result. The opt-in `singleflight=True` prototype takes a local advisory lock per cache key and rechecks the cache after acquiring it. In the threaded reproduction, six calls executed the function three times before the change and once with the prototype. Different keys can still run concurrently. A follow-up moved custom backend validation ahead of cache initialization. The focused suites passed 113 tests and all 33 checks passed on commit `04c7087`. The PR is open for review. Lock-file reclamation and concurrent cache maintenance remain design questions, and the prototype targets local filesystems. [joblib #1946](https://github.com/joblib/joblib/pull/1946)

**Polars.** A small `scan_csv().head()` could prefetch much more data than the slice required. The proposal caps default prefetch for positive slices of up to 1,000 rows and honors explicit environment overrides. On a 40-million-row CSV with 24 threads, three local `head(5)` runs used 102, 104 and 103 MiB peak RSS. Each returned five rows. These are measurements from one workload and environment. [Polars #30700](https://github.com/pola-rs/polars/pull/30700)

**pylavi and Hugging Face.** pylavi removed a deprecated PyPI classifier while keeping its existing Unlicense declaration. The strict package metadata check and 46 tests passed, and the one-line change merged on October 30. On the Hugging Face Hub, the streaming filesystem PR restricts a read-only path to binary read mode. Newer fsspec versions could accept exclusive write modes and discard those writes. The Datasets and Evaluate proposals address custom HTTP user-agent forwarding and import-time lazy loading respectively. [pylavi #88](https://github.com/marcpage/pylavi/pull/88) · [Hub #5287](https://github.com/huggingface/huggingface_hub/pull/5287) · [Datasets #8866](https://github.com/huggingface/datasets/pull/8866) · [Evaluate #833](https://github.com/huggingface/evaluate/pull/833)

## Scientific Python and numerical behavior

**Matplotlib.** Following review, validation moved to `FixedLocator`, where NaN and infinity can be rejected as invalid tick positions before rendering starts. The PR records 566 passing ticker tests and Ruff checks. The fix merged on November 7. [Matplotlib #32575](https://github.com/matplotlib/matplotlib/pull/32575)

**NeuralForecast.** Two open patches address different numerical issues. `MQLoss` and `HuberMQLoss` were using the length of the leading dimension of a reshaped quantile tensor. Using its final dimension gives the intended mean across quantiles and changes gradient scale for multi-quantile training. In RevIN denormalization, a sign-preserving lower bound on the magnitude of the affine denominator prevents division by zero. The PR records 49 passing focused RevIN tests and describes the behavior near zero. [NeuralForecast #1731](https://github.com/Nixtla/neuralforecast/pull/1731) · [NeuralForecast #1734](https://github.com/Nixtla/neuralforecast/pull/1734)

**Scientific APIs and examples.** The merged scikit-image edit documents that the lily microscopy dataset has three fluorescence channels and one DIC channel, with 12-bit precision stored in `uint16`. The pandas reference now exposes `ExtensionDtype.empty` through autosummary. Open documentation PRs explain DIA sparse-storage indexing in SciPy, custom font loading in Matplotlib, slicing in Rust ndarray, and an interactive sphere widget in PyVista. [scikit-image #8389](https://github.com/scikit-image/scikit-image/pull/8389) · [pandas #71798](https://github.com/pandas-dev/pandas/pull/71798) · [SciPy #26592](https://github.com/scipy/scipy/pull/26592) · [Matplotlib #32568](https://github.com/matplotlib/matplotlib/pull/32568) · [ndarray #1626](https://github.com/rust-ndarray/ndarray/pull/1626) · [PyVista #9530](https://github.com/pyvista/pyvista/pull/9530)

**Numerical investigations without submitted patches.** Three local C++ patches exercised SciPy's XSF kernels directly. The complex Legendre recurrence patch passed 16 assertions, the incomplete gamma prefactor patch passed 34, and the convergence patch passed 13. The first two issues already have matching upstream XSF PRs. The convergence patch remains local for human review, particularly around subnormal tails. Validation used standalone C++ tests and high-precision references. Full SciPy integration is pending. [Legendre issue #26452](https://github.com/scipy/scipy/issues/26452) · [XSF #390](https://github.com/scipy/xsf/pull/390) · [Gamma prefactor issue #26535](https://github.com/scipy/scipy/issues/26535) · [XSF #419](https://github.com/scipy/xsf/pull/419) · [Gamma convergence issue #26471](https://github.com/scipy/scipy/issues/26471)

## Compilers, ML systems, and verification

**LLVM/MLIR.** An indirect function with a missing resolver symbol could hit an assertion during verification. The merged fix checks for a null lookup result and lets the verifier emit its existing diagnostic. The added invalid-IR case passed under `llvm-lit`. [LLVM #240111](https://github.com/llvm/llvm-project/pull/240111)

**PyTorch.** The Dynamo proposal preserves explicit dynamic-dimension annotations on parameters. The original recompilation behavior was reproduced on an installed wheel. Runtime validation of the modified source checkout remained pending in the PR record. The Inductor proposal folds eligible foreach copy epilogues while guarding mutation ordering, partial groups, and aliasing. Its controlled comparison reduced the pre-fusion IR from nine nodes to six. CPU tests covered the affected foreach paths, and the PR reports the IR count as a structural result. [Dynamo #203991](https://github.com/pytorch/pytorch/pull/203991) · [Inductor #204039](https://github.com/pytorch/pytorch/pull/204039)

**Runtime and evaluation.** The Claude Agent SDK proposal addresses callback starvation when message consumers stall. The proposed unbounded buffer introduces a memory trade-off if consumers remain stalled. Other open contributions cover fused BERT CPU softmax in Candle, paired toxicity reporting in TrustyAI, and two alpha-beta-CROWN changes involving adversarial input bounds and interval-sensitivity branching. The private top-k proposal in OpenDP was closed without a merge. [Claude Agent SDK #1481](https://github.com/anthropics/claude-agent-sdk-python/pull/1481) · [Candle #4088](https://github.com/huggingface/candle/pull/4088) · [TrustyAI #14](https://github.com/trustyai-explainability/trustyai-detoxify/pull/14) · [alpha-beta-CROWN #110](https://github.com/Verified-Intelligence/alpha-beta-CROWN/pull/110) · [alpha-beta-CROWN #109](https://github.com/Verified-Intelligence/alpha-beta-CROWN/pull/109) · [OpenDP #3141](https://github.com/opendp/opendp/pull/3141)
