## pylavi: remove a deprecated license classifier

In [marcpage/pylavi PR #88](https://github.com/marcpage/pylavi/pull/88), I removed the deprecated `License :: OSI Approved :: The Unlicense (Unlicense)` classifier from `setup.py`. The package retains its existing `license="Unlicense"` metadata; the change does not attempt to relicense the project.

The upstream pull request was merged on October 30, 2026. The PR records a strict package-metadata check and a test run reporting 46 passing tests. This is a small compatibility and maintenance change, not a functional change to the library's behavior.
